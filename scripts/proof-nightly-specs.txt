# The Playwright spec files a full proof defers to the nightly tier and the
# pre-release gate (AGENTS.md §11, docs/PROOFS.md): the spec side of
# scripts/proof-nightly-tests.txt. The list changes only with the user's
# approval, and it is parsed as strictly:
#
#   spec<TAB>covering merge-gate specs<TAB>approved<TAB>reason
#
# A spec is a file under ui/e2e/. Every spec named here must be a listed
# spec file, and every covering spec a listed spec file that is not itself
# on this list; a stale row fails the gate. "Approved" is
# "YYYY-MM-DD <name>": the day the user approved the move, and who asked.
#
# A full proof defers only the rows its base's list also carries, so the
# change that adds a row runs that spec one last time; its tests are
# recorded as deferred in the Playwright ledger. The nightly tier runs
# exactly these specs; the pre-release gate runs everything, these included.
# A red nightly or pre-release proof is a regression on main: fixing it, or
# reverting the change that broke it, is the next work; it holds no other
# merge, and a red pre-release proof holds its release. Never edit this list
# to make a proof pass.
