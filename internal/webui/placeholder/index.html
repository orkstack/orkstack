This engine was built without its web UI

The ork binary serving this page was compiled without the UI's build, so it serves this page in its place. The Connect API, the WebSocket bridge and the plain-HTTP routes on this port work as they always do.

  • Build the UI into ork: run make ui, then build ork again (make build). The release binaries and images, and docker compose up, already carry it.
  • Serve a UI build from disk instead: cd ui && bun run build, then start ork with ORK_UI_DIR naming ui/build.
  • Working on the UI itself: make up serves it with hot reload at http://localhost:5173, proxying the API to this engine.
