# Security policy

**Report a vulnerability privately, never in a public issue.** Use the
repository's [Report a vulnerability](https://github.com/orkstack/orkstack/security/advisories/new)
form (the Security tab), which opens a private advisory that only the
maintainers see. Say what an attacker can do, against which version or
commit, and how to reproduce it.

Fixes ship in the next release, and the advisory is published with it. Only
the latest release is supported. OrkStack is maintained on a best-effort
basis, so no response time is promised.

What OrkStack defends, and what it leaves to the deployment, is in
[docs/SECURITY_MODEL.md](docs/SECURITY_MODEL.md).
