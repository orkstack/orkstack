# The cosign image that signs what a release publishes
# (.github/workflows/release.yml) and signs the release smoke's images with a
# throwaway key (scripts/quickstart-smoke.sh --release), pinned by its
# multi-arch index digest. Both sign in cosign 3's own bundle format, which
# OrkStack's verifier reads, under deploy/cosign-signing-config.json, a
# signing config that names no service, so nothing is written to a
# transparency log and no deprecated flag is passed (docs/DEPLOY.md, "Image
# supply-chain policy"). internal/dsl's bundle interop test runs it too. A
# bump is a pull request that proves it with the release smoke and that test.
